# Image reference implementation

Image 1 has been extracted into 14 numbered PNG reference panels in this folder. Cropping preserves the supplied pixels; these are small reference images, not high-resolution source artwork.

The frontend uses the exact supplied image 2 at public/campusbite-logo.jpeg, displayed at the top left. The homepage uses the building crop from image 1 (public/reference-campus.png); provide an original campus photograph for a sharper desktop result.

Implemented reference styling: ivory background, navy actions, muted gold accents, serif headings, campus-photo homepage and food callout, category image tiles, compact food rows, mobile navigation. Existing login, signup, dashboard, cart, pickup, simulated payment, invoice and tracking routes remain functional demo screens with the shared reference palette. This is a responsive recreation, not a pixel-exact reproduction of every small panel.
